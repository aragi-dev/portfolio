# ttfx v0.3.2 (vendored)

Terminal text effects engine, MIT licensed, a port of
TerminalTextEffects by ChrisBuilds. The original copyright is preserved
in `LICENSE` and `NOTICE`.

- Source: https://github.com/omacom/ttfx
- These files are its unmodified wasm-bindgen build: `0.3.2/ttfx.js`
  (JS glue), `0.3.2/ttfx.d.ts` (types), and `effects/all.wasm` (bundle
  of all 37 effects).
- Obtained via the omacom-io/omarchy-site distribution (`public/ttfx/`);
  `LICENSE` and `NOTICE` come verbatim from the ttfx repository.
